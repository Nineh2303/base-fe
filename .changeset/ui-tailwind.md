Tailwind v4 and the new `@nineh2303/ui` component package (shadcn-vue style). mf-core: shadcn theme tokens, per-remote scope element (`data-mf-remote`) with a portal container, `MF_PORTAL_KEY` and `useMfPortalTarget`. mf-vite: Tailwind plugin by default (`tailwind: false` opts out) and automatic ui/reka-ui singleton sharing. create-mf: templates use ui, plus `ui add <component...>` to eject component source.
